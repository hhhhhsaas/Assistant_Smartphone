1. GIỚI THIỆU BÀI TOÁN
================================================================================

Vấn đề thực tế:
- Thị trường có hàng trăm mẫu điện thoại với vô số thông số kỹ thuật phức tạp
- Người dùng thường không am hiểu về chip, RAM, camera...
- Họ chỉ biết nhu cầu: "Tôi cần điện thoại chơi game", "pin trâu", "chụp ảnh đẹp"
- Các website bán hàng chỉ có bộ lọc cứng, không hiểu ngôn ngữ tự nhiên

Giải pháp của chúng tôi:
- Xây dựng HỆ CHUYÊN GIA mô phỏng tư duy của người tư vấn điện thoại
- Input: Câu tiếng Việt tự nhiên
- Output: Top điện thoại phù hợp + giải thích tại sao

2. CÔNG NGHỆ SỬ DỤNG
================================================================================

1) FORWARD CHAINING (Suy luận tiến)
   - Xuất phát từ facts ban đầu
   - Áp dụng rules IF-THEN để suy ra facts mới
   - Lặp lại cho đến khi không còn rule nào fire được

2) FUZZY LOGIC (Logic mờ)
   - Xử lý các khái niệm mờ: pin "trâu", camera "đẹp", giá "rẻ"
   - Dùng hàm membership để tính độ phù hợp
   - Cho phép đánh giá theo nhiều tiêu chí cùng lúc

3) NLP PARSER
   - Hiểu tiếng Việt tự nhiên
   - Nhận dạng: nhu cầu, ngân sách, thương hiệu, tính năng

4) TECH STACK
   - Python: Backend processing
   - Streamlit: Web UI
   - Pickle: Lưu trữ Knowledge Base

4. QUY TRÌNH XỬ LÝ - 5 BƯỚC
================================================================================

INPUT: "Điện thoại chơi game tầm 15 triệu"

-------------------
BƯỚC 1: NLP PARSING
-------------------
Phân tích câu tiếng Việt thành dữ liệu có cấu trúc:

- "chơi game" → user_need = "gaming"
- "tầm 15 triệu" → budget = 16.5 triệu, budget_min = 13.5 triệu (±10%)
- "Samsung" → preferred_brand = "Samsung"
- "có NFC" → required_nfc = True

Output: {
    "user_need": "gaming",
    "budget": 16500000,
    "budget_min": 13500000
}

-----------------------
BƯỚC 2: FORWARD CHAINING
-----------------------
Đánh giá 66 rules theo thứ tự priority:

Rule R1_GAMING_HIGH (priority=10):
IF user_need = "gaming" AND budget >= 15000000
THEN
    category_filter = ["gaming", "flagship"]
    min_ram = 12GB
    min_processor_tier = "high"
    min_refresh_rate = 120Hz

Conflict Resolution:
- Rules sắp xếp theo priority (10 → 0)
- Working Memory merge thông minh:
  + min_battery: lấy MAX
  + category_filter: UNION các categories
  + preferred_brands: UNION các brands

Output: Inferred facts {
    "category_filter": ["gaming", "flagship", "midrange"],
    "min_ram": "12GB",
    "min_processor_tier": "high",
    "min_refresh_rate": 120
}

-------------------------------------
BƯỚC 3: KNOWLEDGE BASE SEARCH + FILTER
-------------------------------------
Gồm 2 giai đoạn:

KB Search (tìm kiếm thô):
- Lọc theo budget: 13.5 - 16.5 triệu
- Lọc theo category: gaming, flagship, midrange
- Lọc theo brand (nếu có)
- LOẠI BỎ phones price=0 ("Liên Hệ")
→ 525 phones → 45 candidates

Filtering (lọc tinh):
- Check RAM >= 12GB
- Check processor tier >= "high"
- Check refresh rate >= 120Hz
- Check các features: NFC, 5G, wireless charging...
→ 45 candidates → 22 phones pass

-----------------------
BƯỚC 4: FUZZY LOGIC SCORING
-----------------------

Tính điểm mờ cho từng phone qua 6 tiêu chí:

1) Performance (Hiệu năng)
   - Processor tier: low → mid → upper-mid → high
   - Snapdragon 8 Gen 3 → "high" → score 1.0

2) Battery (Pin)
   - Yếu: < 3500mAh (score 0.2)
   - Trung bình: 3000-4500mAh (score 0.5)
   - Khỏe: 4000-5000mAh (score 0.8)
   - Rất khỏe: > 5000mAh (score 1.0)

3) Camera
   - Cơ bản: < 20MP
   - Tốt: 16-48MP
   - Rất tốt: 32-108MP
   - Chuyên nghiệp: > 64MP

4) RAM: 4GB → 8GB → 12GB → 16GB+

5) Screen: Kích thước + Refresh rate

6) Price (Budget-aware - CẢI TIẾN MỚI)
   Thay vì phân loại tuyệt đối, tính theo tỷ lệ giá/ngân sách:

   ratio = phone_price / user_budget
   - ratio 50-100%: Score 0.9-1.0 (Tốt nhất)
   - ratio 30-50%: Score 0.6-0.9 (Chấp nhận)
   - ratio < 30%: Score 0.3-0.6 (Quá rẻ, thiếu tính năng)
   - ratio > 110%: Score giảm nhanh (Vượt budget)

TRỌNG SỐ BẤT ĐỐI XỨNG theo nhu cầu:

Gaming:      Performance 35%, Screen 30%, RAM 15%, Battery 12%, Price 5%, Camera 3%
Photography: Camera 50%, Performance 15%, RAM 10%, Battery 10%, Price 10%, Screen 5%
Battery:     Battery 55%, Performance 15%, Price 15%, RAM 8%, Screen 5%, Camera 2%
Student:     Price 40%, Camera 20%, Battery 15%, Performance 10%, RAM 10%, Screen 5%

Công thức tổng:
Total Score = Fuzzy Score × 0.7 + Rule Compliance × 0.3

Nếu phone có price=0 (không biết giá):
Total Score × 0.6 (penalty)

------------------------
BƯỚC 5: RANKING & OUTPUT
------------------------

Sắp xếp theo Total Score giảm dần:

1. OPPO Reno14 5G (79%)
   - Snapdragon 8 Gen 2
   - 12GB RAM
   - Màn hình 120Hz
   - Giá 16 triệu (97% budget)

2. OPPO Find X5 Pro (79%)

   - Giá 16 triệu

3. HONOR Magic 7 Pro (77%)

Tạo giải thích:

✓ Màn hình refresh rate cao cho gaming
✓ Pin đủ dùng
✓ Giá nằm trong ngân sách
